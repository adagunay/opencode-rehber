Opencode Nedir?

Opencode, açık kaynak kodlu bir yapay zekâ kod asistanıdır. Proje klasörünü analiz eder; kod yazar, dosyaları düzenler ve sistem komutlarını kullanıcının onayı ile çalıştırır.

  • Açık kaynak: Kaynak kodu https://github.com/anomalyco/opencode adresinde paylaşılmaktadır.
  • Çoklu platform: Terminal arayüzü (TUI), masaüstü uygulaması ve IDE eklentisi olarak kullanılabilir.
  • Çoklu model: Anthropic, OpenAI, Google gibi sağlayıcıların modelleriyle çalışır. Desteklenen modeller https://models.dev üzerinden listelenir.
  • Çalışma prensibi: Proje dosyalarını bağlam (context) olarak kullanır; her işlemi kullanıcı onayına sunar.

Kurulum

Masaüstü (Desktop) Uygulaması

Kurulum için resmi sitedeki talimatları izleyin: https://opencode.ai. Masaüstü uygulaması, opencode.ai sitesinden veya GitHub Releases sayfasından indirilir. Windows ve macOS sürümleri mevcuttur.

Kurulum sonrasında tek yapılması gereken, bir model sağlayıcısına bağlanmaktır.

Model Sağlayıcısına Bağlanma

TUI’de /connect komutunu çalıştırın, OpenCode Zen’i seçin ve API anahtarınızı yapıştırın.

Alternatif olarak opencode auth login ile giriş yapılabilir; kayıtlı sağlayıcılar opencode auth list komutuyla görüntülenir.

İlk Kullanım

Uygulamayı açtıktan sonra bir proje klasörü seçin. Karşınıza sohbet arayüzü gelir. /init komutu, seçilen klasörü analiz ederek projeyi tanıtır.

İpucu: İstekler ne kadar açık ve ayrıntılı olursa yanıtlar o kadar başarılı olur.

Model Seçimi: Hangi Yapay Zekâ Modelini Kullanmalı?

Model tanımı sağlayıcı/model biçimindedir. Örneğin anthropic/claude-sonnet-4-6, Anthropic'in claude-sonnet-4-6 modelidir. Model tercihi; işin niteliğine, bütçeye ve bağlam (context) gereksinimine göre değişir.

Varsayılan model, opencode.json dosyasından belirlenir:

{
  "model": "anthropic/claude-sonnet-4-6"
}

OpenCode Zen: Anahtar Gerektirmeyen Başlangıç

API anahtarı edinmeden çalışmak için OpenCode Zen modelleri kullanılır. Bunlar opencode/ önekiyle listelenir (ör. opencode/deepseek-v4-flash-free); adının sonunda -free bulunan modeller ücretsizdir. Bağlantı /connect → opencode (Zen) ile yapılır.

Zen Modelleri ve Kod Adları

Zen üzerinden sunulan bazı modeller kod adlarıyla (codenames) yayınlanır (ör. opencode/big-pickle). Arkasındaki model OpenCode tarafından belirlenir ve zamanla güncellenebilir.

Sağlayıcı modelleri ile Zen modelleri arasındaki temel farklar:

Sağlayıcı modelleriOpenCode Zen modelleri
API anahtarıSağlayıcıdan alınırGerekmez; OpenCode hesabı yeterlidir
ÜcretlendirmeSağlayıcının fiyat politikasıZen üzerinden; bazı modeller ücretsiz
Model kimliğiİsimde belirtilen model sabittirKod adının arkasındaki model değişebilir
Örnekanthropic/claude-sonnet-4-6, openai/gpt-5opencode/big-pickle, opencode/deepseek-v4-flash-free

Kod adları, hangi modelin kullanıldığı konusunda garanti vermez. Kritik işlerde sağlayıcı modeli, deneme amaçlı çalışmalarda Zen modelleri tercih edilmelidir.

Galaxy MCP Kurulumu

MCP Nedir? (Model Context Protocol)

MCP (Model Context Protocol), yapay zekâ asistanlarına harici araç ve veri kaynaklarının bağlanmasını sağlayan açık bir protokoldür. Galaxy MCP sayesinde Opencode, Galaxy platformuna bağlanarak history oluşturma, veri yükleme, analiz araçlarını çalıştırma ve workflow yönetimi gibi işlemleri komut satırından gerçekleştirir.

1. galaxy-mcp Kurulumu

Python kurulu olmalıdır:

pip install galaxy-mcp

Kurulumun başarılı olduğu galaxy-mcp --help komutuyla doğrulanabilir.

2. Galaxy'den API Anahtarı Alma

  1. usegalaxy.org (veya usegalaxy.eu / usegalaxy.org.au) sitesine giriş yapın.
  2. User → Preferences → Manage API Key bölümüne gidin.
  3. 32 karakterlik anahtarı kopyalayın (ör. abcd1234...).

3. Opencode Konfigürasyonu

MCP sunucusu, opencode.json (global: ~/.config/opencode/opencode.json, proje: ./opencode.json) içine şu şekilde eklenir:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "galaxy": {
      "type": "local",
      "command": ["C:\\Users\\SizinKullanici\\AppData\\Local\\Python\\...\\Scripts\\galaxy-mcp.exe"],
      "enabled": true,
      "env": {
        "GALAXY_URL": "https://usegalaxy.org",
        "GALAXY_API_KEY": "API_ANAHTARINIZ"
      }
    }
  }
}

Dikkat edilmesi gerekenler:

  • command alanı bir dizi (array) olmalıdır; tek bir metin değeri kabul edilmez.
  • galaxy-mcp.exe yolunu where galaxy-mcp komutuyla tespit edip değiştirin.
  • GALAXY_API_KEY alanına kendi anahtarınızı yazın; anahtar kod deposuna (ör. GitHub) yüklenmemelidir.
  • enabled: true bağlantıyı etkinleştirir.

Ayar değişiklikleri, Opencode yeniden başlatıldığında devreye girer.

4. Doğrulama ve Kullanım

opencode mcp list

Listede galaxy görünüyorsa bağlantı hazırdır. Ardından sohbette doğal dilde istekler yazılabilir:

History'lerimi listele
"RNA-seq analizi" adında yeni bir history oluştur

Uzak (Remote) MCP Kullanımı

Bazı MCP sunucuları, yerel kurulum gerektirmeden HTTP üzerinden bağlanır:

{
  "mcp": {
    "galaxy-uzak": {
      "type": "remote",
      "url": "https://ornek-sunucu.com/mcp",
      "enabled": true
    }
  }
}

OAuth gerektiren sunucularda opencode mcp auth <sunucu-adi> komutu, tarayıcıda yetkilendirme başlatır.
